# Your Spotify fork identity

The listening-history symbol and wordmark were generated with Codex for this fork, following the owner's choice of an abstract listening-history mark. They are not Spotify branding and do not imply affiliation.

- `wordmark.png`: trimmed, resized original composition.
- `symbol.png`: symbol extracted from the same composition, used as a CSS mask so it inherits each theme's text color.
- `social.png`: original wordmark on an ivory background for link previews.
- `../logo192.png`, `../logo512.png`, `../favicon.ico`: app icons derived from the symbol, with white ink on a dark field.

Generation prompt: “Design a logo for Your Spotify. Listening-history symbol: an abstract mark inspired by recorded listening and music, with the Your Spotify name. Sophisticated, snappy, but not trying too hard, just professional and cool. A simple mark that works in one color will fit all four themes without resembling Spotify’s branding. Produce one final image.”
